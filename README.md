# Emaan S — Premium Dark Portfolio

## Open locally
1. Unzip the folder.
2. Open the folder in VS Code.
3. Double-click `index.html` or run it using the VS Code Live Server extension.

## Customize
- `index.html`: text, experience, projects, contact information, links.
- `style.css`: colors, typography, layout, responsive breakpoints.
- `script.js`: typing animation, scroll reveal, mobile menu, theme toggle.
- `assets/profile.jpg`: original third photo provided by the user (not AI-reconstructed).
- `assets/Emaan_S_Resume.pdf`: original supplied PDF. It contains overlapping text in its experience section; consider replacing it with a clean updated PDF before publishing.

## Check before publishing
- The source resume text extraction showed two inconsistent Music Player links (`ke-spotify.netlify.app` and `re-spotify.netlify.app`). This website uses `https://re-spotify.netlify.app/`; check which one is correct.
- The resume's AR Caller dates are garbled/overlapping; this site deliberately says "6 months" and "previous role" without inventing dates.
- CGPA is left as a confirmation placeholder.
- No GitHub account or project repository URL was provided; none has been invented.
- The original resume contains a street address; this portfolio intentionally omits it for public privacy.
- Google Fonts load from the internet; fallback system fonts work offline.

## Deploy
Push these files to a GitHub repository and enable GitHub Pages in Settings > Pages, or import the repository into Vercel. Make sure the project link is checked first.

PUBLIC-SHARING NOTE: This package includes a public-safe resume without home address or phone number. Contact via email or LinkedIn. Public GitHub files remain accessible to others.
